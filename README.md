# Bundle Builder

A two-step-flow bundle builder: a multi-step accordion on the left for picking cameras, a plan, sensors, and accessories, with a live review panel on the right that stays in sync as you go.

Built with React 19, TypeScript, Vite, Tailwind CSS v4, and Zustand for cart state.

## Running it

```bash
git clone https://github.com/DaliaAdel262/Frontend-Take-Home-Bundle-Builder.git
cd Frontend-Take-Home-Bundle-Builder/bundle-builder
npm install
npm run dev
```

Opens at `http://localhost:5173`.

Other scripts, run from `bundle-builder/`:

```bash
npm run build    # type-checks and builds for production
npm run preview  # serves the production build locally
npm run lint     # eslint
```
